A child-sized robot at a public demo stand greets strangers, talks with them and does one small physical thing. Think of it as a puppet theatre with one stage manager. Each interaction story is one act; the robot is the puppet. Flip to Engineer view to see the real names.

2The voice asks. The stage manager calls.

The voice improvises every line. It can never touch the strings. When it wants the puppet to move, it writes a slip.

Mid-greeting, the voice asks the puppet to hand over a gift. This beat's page does not list a gift. What happens?

3An act is a cue sheet: given this, do that

The wave act has three beats: greet, wait for a wave, wave. Time is a cue too: the wait has a timer. Move the wave, and change who waves.

The page reads no clock and touches no station. It only asks. So the same events always give the same show, and every run can be replayed exactly. B1

4The stations decide what may overlap

The crew has three stations: the control bar, the follow-spot and the microphone. Each cue claims the stations it needs.

The puppet is waving. Can the voice keep talking?

5The safety curtain comes down first

Every note to the stage arrives at one stage door, in one queue, with one stage manager reading it. The act's page sees only what the stage manager hands over.

Every act climbs the same ladder. The rehearsal room keeps the same stage manager and the same pages; only the world around them is stand-ins.

Where the theatre breaks

  • A stage manager uses judgement. The kernel has none: it is deterministic code with closed rules, and every decision is replayable.
  • In a theatre the safety curtain is the guarantee. On the robot the guaranteed stop is hardware; the kernel's interception is an extra layer that makes the story behave well when it acts.
  • A voice actor knows the show has limits. The reasoner is never told it is bounded; it sees a small context per beat and one tool that returns a request.
  • A theatre can swap acts in an interval. Here an act is fixed for the life of one coordinator process; a switch is a full stop–clean–restart that takes minutes.
  • A theatre rehearsal room usually lacks the real crew. The simulation keeps the real behaviour engine, motion layer and coordinator in the loop and replaces only the world.
