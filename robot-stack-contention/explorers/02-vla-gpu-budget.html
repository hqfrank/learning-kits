The VLA's GPU need is its GPU time per call × rate, not its call time × rate: each call also contains CPU-side time (note C1). Without MPS the GPU time-slices between processes (note B1), so the VLA can only use the GPU time that the stack's services leave, and sharing costs extra GPU time per output.
