An odd log window is isolated after a few random splits — that short path is its anomaly score

Each dot is one window of a device log, reduced to a count vector with two entries: how many times a "connected" template and a "disconnected" template occurred in it (note B2). The windows and their counts are illustrative, drawn by a seeded generator on this page. A real isolation forest (Liu, Ting, Zhou 2008) is built in your browser: each tree splits on a random feature at a random value until each window is alone. Windows that need few splits score near 1; a window that needs the average number of splits scores 0.5 (note B3).

Move the tree count, the sub-sample size and the contamination; then move the probe window and watch its path length and score.

Default from the paper and scikit-learn (see sources). More trees average out the randomness of one tree.
ψ = 2k points per tree, 16 … 256. The default is 256. ψ sets the height limit ⌈log₂ ψ⌉ and the normaliser c(ψ).
0 = 'auto': flag score > 0.5. Otherwise the threshold flags that share of the training windows. You choose this number; the data do not.
The probe is scored by the forest; it is not in the training set.

Parameters & sources

Every constant is loaded from the inlined params block (also shipped as params.json), copied from ../constants.json. public = a cited paper or documentation. illustrative = a round teaching number, never a measurement. The training windows themselves are generated on this page (seed 7, illustrative): "connected" ~ Poisson(λ), "disconnected" ~ Poisson(0.15 λ + 0.3), λ uniform in 4 … 16, 400 normal windows plus 6 planted odd ones. Self-tests: not run.
