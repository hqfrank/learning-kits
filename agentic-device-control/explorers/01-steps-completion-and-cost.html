A 90 % step is a 59 % task: per-step reliability compounds, recovery breaks the product, and caching sets the bill

An agent task needs several correct steps (taps, routes). If each step succeeds with probability p and nothing recovers a wrong step, the task succeeds with probability pn (note 09). The ReAct loop (note 06) lets the agent see a wrong screen and try again, which costs one more step and one more model call. The step limit caps that, and prompt caching (note 07) sets what each call costs. Move the sliders; every default is an illustrative value from the kit's constants.json. Nothing on this page is a measurement.
