The planner never touches the screen: every specialist turn returns to the orchestrator, and three limits bound the loop

Step one task through the agent graph of note 02: START (the message guards of note 01) → orchestrator → router → vision specialist or actuator → back to the orchestrator → FINISH → END. Each vision iteration is one ReAct cycle (note 06): thought, action, observation. Pick a case, step with the buttons or the arrow keys, and move the limits to see which one stops a bad run. All times, token counts and limits are illustrative values from constants.json; the tasks and screens are invented for this page.
